== Description ==

Готовый WordPress плагин для входа и регистрации через Яндекс на сайт Wordpress и Woocommerce. Мы разработали и выложили в открытый доступ плагин Login via Yandex. Вы можете ознакомиться с текстовым руководством по интеграции ниже, либо посмотреть видео-руководство в конце данного описания.

**Использование сервиса Яндекс ID и политика конфиденциальности Яндекс ID**
Плагин интегрирует авторизацию на ваш сайт через сервис Яндекс ID. Устанавливая данный плагин, вы соглашаетесь на условия использования сервиса Яндекс ID в соответствии с Политикой конфиденциальности и условия использования сервиса Яндекс ID.

== Installation ==

**Видео руководство по установке плагина**

https://www.youtube.com/watch?v=iEn4-2ybuHI

**Создание приложения в Яндекс ID**

1. Для начала, вам понадобится [перейти по ссылке](https://oauth.yandex.ru/client/new/id/) и создать своё приложение в Яндекс, заполнив анкету из четырех шагов. В поле Webhook URI необходимо обязательно указать адрес, заменив «вашсайт.ру» на ваше доменное имя, пример:

*https://вашсайт.ру/wp-json/login_via_yandex/webhook*

2. После заполнения, вы получите ClientID и Client Secret, эти токены пригодятся при настройки плагина на стороне WordPress.

3. После создания приложения в Яндексе, необходимо скачать, установить и настроить сам плагин.
4. После скачивания и установки плагина, переходим в "Настройки"->"Вход через Яндекс" и заполняем обязательные поля ClientID и Client secret, а также выбираем тип отображения на сайте.

**Доступны следующие варианты отображения**

– Конфигуратор кнопки — полная настройка внешнего вида: вид (main, additional, icon), светлая/тёмная тема кнопки, размеры (xs...xxl), тип иконки (ya, yaEng) и радиус скругления углов (0...14).
– Шорткод — используйте `[login_via_yandex]` или `[yandex_login]` с поддержкой параметров (`view`, `theme`, `size`, `radius`, `icon`) для размещения кнопки в любом месте: в Elementor, Gutenberg, сайдбаре, модальном окне или PHP-шаблоне.
– Автоматическое размещение — автоматический вывод кнопок входа под стандартными формами входа и регистрации WordPress и WooCommerce.
– Виджет мгновенного входа — всплывающий блок авторизации Яндекс ID поверх страницы.
